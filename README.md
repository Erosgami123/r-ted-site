# Site officiel R-TED

Site vitrine de R-TED, société française spécialisée dans l'achat, la vente et la location d'aéronefs et d'équipements associés.

## Publication

Le site est conçu pour GitHub Pages et utilise le domaine personnalisé `r-ted.site`.

## Important

L'adresse `contact@r-ted.site` doit être créée auprès d'un fournisseur de messagerie avant son utilisation commerciale.
